This PR adds a custom tooltip wrapper to the admin `IconButton` component, replacing the native `title` attribute with the design system's `Tooltip`. This improves the visual consistency of hover states across the application while maintaining accessibility.

## Summary
💡 What: Added the custom `Tooltip` wrapper to the admin `IconButton` component and removed the native `title` attribute.
🎯 Why: Provides a more consistent, immediate, and aesthetically pleasing hover state for users without relying on the native browser tooltip which doesn't match the design system.
📸 Before/After: Verified visually via Playwright script.
♿ Accessibility: Retained the `aria-label` attribute on the inner `Button` while removing the native `title` attribute, preventing potential redundant announcements by screen readers while keeping full keyboard and screen reader accessibility intact.
