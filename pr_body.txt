## Summary
🎨 Palette: Localize 'Clear input' label in macOS Input component

**What**: Replaced the hardcoded "Clear input" string in the macOS `Input` component with the `t('common.clear', { defaultValue: 'Clear input' })` i18n hook. The `common.clear` key was added to all language locales (`ru.ts`, `en.ts`, `kk.ts`, `uz-Cyrl.ts`, `uz-Latn.ts`). Also fixed unit tests that were failing due to the change by using correct substring matches.
**Why**: Ensures non-English users understand what the trailing "X" button does, especially those relying on screen readers.
**Accessibility**: The `aria-label` and `title` properties on the clear button are now localized, ensuring international users receive correct auditory feedback.
