## Summary
🎨 Palette: Add `aria-invalid` attribute to communicate error states to screen readers.

### 💡 What
Added `aria-invalid={!!error}` to the underlying interactive elements within the custom `macos` form controls (`Input`, `Textarea`, `Select`, `Checkbox`).

### 🎯 Why
Currently, visual error states (like red borders when validation fails) on these custom form components are completely invisible to screen reader users. Relying solely on color to convey state is an accessibility violation. Adding `aria-invalid` properly communicates the error state to assistive technologies.

### 📸 Before/After
Not a visual change, purely an accessibility enhancement.

### ♿ Accessibility
Screen reader users will now correctly hear "invalid" or similar announcements when focusing on a form field that is in an error state.
