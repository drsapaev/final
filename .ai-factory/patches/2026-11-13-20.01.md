# Queue profile deletion feedback

**Date:** 2026-11-13 20:01
**Files:** frontend/src/components/admin/QueueProfilesManager.tsx; frontend/src/components/admin/__tests__/QueueProfilesManager.interactions.test.tsx
**Severity:** low

## Problem

An administrator could miss the server's refusal to delete a queue profile when the affected row was below the global error banner.

## Root Cause

The deletion error was rendered only above the table and was not announced as an alert or brought into view.

## Solution

Display and announce the refusal beside the affected row, with an independent fallback identifying the profile when the row is filtered out. Preserve the existing server guard and translations.

## Prevention

Cover failure feedback near its initiating action, including filtering and simultaneous errors.
