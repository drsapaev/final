# Измерения трансторакальной ЭхоКГ у взрослых

Каноническая форма ЭхоКГ записывает числовые значения из исследования в `data.specialty_data.echo.adult_tte`. Поле `version` равно `2`. В `measurements` каждый заполненный ключ содержит число `value` и фиксированную единицу `unit`. Пропущенные измерения отсутствуют. Форма принимает точку и запятую в качестве десятичного разделителя.

| Группа | Ключ | Измерение | Единица |
| --- | --- | --- | --- |
| Основная | `lvef` | Фракция выброса ЛЖ | % |
| Основная | `lvedv` | Конечный диастолический объём ЛЖ | mL |
| Основная | `lvesv` | Конечный систолический объём ЛЖ | mL |
| Основная | `lavi` | Индекс максимального объёма ЛП перед открытием митрального клапана | mL/m² |
| Расширенная | `lvedd` | Конечный диастолический размер ЛЖ | cm |
| Расширенная | `lvesd` | Конечный систолический размер ЛЖ | cm |
| Расширенная | `ivsd` | Толщина межжелудочковой перегородки в конце диастолы | cm |
| Расширенная | `pwd` | Толщина задней стенки ЛЖ в конце диастолы | cm |
| Расширенная | `lvedvi` | Индекс конечного диастолического объёма ЛЖ | mL/m² |
| Расширенная | `lvesvi` | Индекс конечного систолического объёма ЛЖ | mL/m² |
| Расширенная | `rv_basal_diameter` | Базальный размер ПЖ в конце диастолы в ПЖ-ориентированной апикальной позиции | cm |
| Расширенная | `tapse` | Систолическая экскурсия латеральной части кольца трикуспидального клапана в M-режиме | cm |
| Расширенная | `rv_s_prime` | Систолическая скорость S′ латеральной части кольца трикуспидального клапана по тканевому допплеру | cm/s |
| Расширенная | `rv_fac` | Фракционное изменение площади ПЖ | % |
| Расширенная | `aov_vmax` | Пиковая скорость на аортальном клапане по постоянноволновому допплеру | m/s |
| Расширенная | `aov_mean_gradient` | Средний градиент на аортальном клапане по постоянноволновому допплеру | mmHg |
| Расширенная | `ava_continuity` | Площадь аортального клапана по уравнению непрерывности | cm² |

Врач переносит ФВ, объёмы, индексы, фракционное изменение площади ПЖ и площадь аортального клапана из исследования. Программа хранит введённые значения. Поле ФВ принимает одно число. Диапазон оценки можно внести в заключение по данным исходного исследования.

| Код `ef_method` | Метод определения ФВ ЛЖ |
| --- | --- |
| `biplane_simpson_2d` | Биплановый метод дисков Симпсона в 2D |
| `volumetric_3d` | Объёмная оценка в 3D |
| `visual_estimate` | Визуальная оценка |
| `linear_2d` | Линейный метод в 2D |
| `other` | Другой метод, который можно уточнить в заключении |

При выборе «метод не указан» ключ `ef_method` отсутствует. Врач вводит дату исследования в `measured_at` в формате `YYYY-MM-DD`. `recorded_at` содержит время записи в ЭМК, а `source_visit_id` указывает на визит, к которому относится запись. Прежние значения остаются в исходных полях вместе с их версией, методом и датой. Например, линейный размер ЛП и индекс объёма ЛП отражаются разными измерениями.

- Состав и единицы измерений, а также запись ФВ с методом определены по таблицам 6 и 10 рекомендаций ASE 2025. [Рекомендации по стандартизации отчёта взрослой ЭхоКГ](https://www.asecho.org/wp-content/uploads/2025/09/PIIS0894731725002925.pdf)
- Биплановая и трёхмерная оценка ФВ, объёмов ЛЖ и количественная оценка ЛП описаны в рекомендациях ASE/EACVI 2015. [Количественная оценка камер сердца](https://academic.oup.com/ehjcimaging/article/16/3/233/2400086)
- Методика получения базального диаметра ПЖ, TAPSE, S′ и FAC описана в рекомендациях ASE 2025. [Эхокардиографическая оценка правых отделов сердца](https://www.asecho.org/guideline/right-heart-in-adults-pulmonary-hypertension/)
- Постоянноволновой допплер и уравнение непрерывности для площади аортального клапана описаны в рекомендациях EACVI/ASE 2017. [Эхокардиографическая оценка аортального стеноза](https://www.asecho.org/guideline/update-of-aortic-valve-stenosis/)
