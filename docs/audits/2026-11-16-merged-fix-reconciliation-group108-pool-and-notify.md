## 2. `DERMAGALLERY-FE-007`: independently reproduced by source, proposed narrow Draft fix [#4103](https://github.com/drsapaev/final/pull/4103)

The issue is **source-observed conditional liveness**, not a measured incident.

**Separate implementation PR created as Draft**: [#4103](https://github.com/drsapaev/final/pull/4103), base `e3addd044`, head `03b46147e0f19d431377c625012af0bb09400ada`.
