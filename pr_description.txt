## Summary
🎨 Palette: Add aria-hidden to StatCard loading skeletons

**💡 What:**
Added `aria-hidden="true"` to the purely visual placeholder/skeleton `<div>` elements inside `StatCard.tsx`'s loading state.

**🎯 Why:**
When a container has `aria-busy="true"` and `role="status"`, screen readers will automatically announce the loading state. However, they can still try to interpret the inner empty `div` tags used for visual styling (skeleton loader). Explicitly hiding them prevents screen reader "noise" or confusion.

**📸 Before/After:**
Visual changes: None.

**♿ Accessibility:**
Improves screen reader experience by eliminating noise from empty DOM nodes inside the loading skeleton of the `MacOSStatCard` component.
